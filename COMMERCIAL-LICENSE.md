# Commercial licensing

FrameTrue is published as source-available software so developers can inspect, test, evaluate, and contribute to the implementation.

Commercial or production integration before the Change Date requires a separate written license from the Licensor.

Examples include:

- integration into a proprietary camera or gallery application;
- integration into device firmware or an operating-system camera/media stack;
- shipping FrameTrue-derived code in a paid, ad-supported, subscription, or otherwise commercial product;
- preinstallation on commercial hardware.

No public per-device royalty is fixed in this repository. Commercial terms are negotiated case by case.

Until a dedicated licensing contact is published, open a GitHub issue titled `Commercial licensing inquiry` without including confidential information.
